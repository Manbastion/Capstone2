# Adelaide University ICT Capstone Project
Grasshopper-HabSim Bridge 🌑

---

## Project Overview

This project aims to create an interface between Grasshopper and HabSim a MATLAB-based lunar simluation. Currently the workflow involving Grasshopper and HabSim is manual and tedious. Therefore, the goal of the project is to develop a method to automate the transfer of habitat design data from Grasshopper to HabSim 

## Languages/Technologies
- Grasshopper
- Rhino3D
- Python
- MATLAB
- HabSim
